# Dropoly

Мобильная казуальная головоломка в жанре number merge drop (в духе Drop the Number, 2248, Merge Block).

- Тап по колонке — плитка падает и сливается с соседями того же номинала (степени двойки)
- Каскадные слияния, очки за номинал × множитель каскада
- Бесконечный забег без уровней, цель — рекорд очков и максимальный номинал
- Ежедневный челлендж с фиксированным seed — у всех игроков одна последовательность плиток
- Полностью оффлайн, Android и iOS

Разработано на Flutter.
